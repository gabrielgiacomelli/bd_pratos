# Controle de Pratos do Restaurante

Nesse projeto é possível ter o controle sobre o estabelecimento do restaurante!

## Funcionalidades: 

| ID | Tipo | Descrição |
| :---: | :---: | :--- |
| **RF1** | Requisito Funcional | **Cadastrar Usuário:** O sistema deve permitir cadastrar usuários informando nome e e-mail. |
| **RF2** | Requisito Funcional | **Cadastrar Prato:** O sistema deve permitir que um usuário cadastre um prato informando nome, descrição, preço e categoria. |
| **RF3** | Requisito Funcional | **Listar Pratos:** O sistema deve apresentar todos os pratos cadastrados, informando também o usuário responsável pelo cadastro. |
| **RF4** | Requisito Funcional | **Editar Prato:** O sistema deve permitir alterar as informações de um prato já cadastrado. |
| **RF5** | Requisito Funcional | **Excluir Prato:** O sistema deve permitir excluir um prato já cadastrado. |
| **RF6** | Requisito Funcional | **Listar Pratos por Usuário:** O sistema deve permitir visualizar os pratos cadastrados por um determinado usuário. |
| **RNF1** | Requisito Não Funcional | **Validação dos Campos:** O sistema não deve permitir o cadastro de usuários ou pratos com campos obrigatórios vazios. |
| **RNF2** | Requisito Não Funcional | **Segurança dos Dados:** As operações que recebem informações fornecidas pelo usuário deverão utilizar Prepared Statements. |
